ChameleonUI

SolidJS 组件库 · Tailwind CSS4

✅ 基于 SolidJS 2 + @solidiom 底层

✅ 内置 Menu / Dialog / Tooltip / ToggleGroup / CheckboxGroup / Toast

✅ 响应式、自动方向判断、无额外 heavy 依赖

✅ 适配 Tailwind CSS4，样式完全可控

产品介绍

ChameleonUI 是面向业务后台开发的 SolidJS 组件库，聚焦常用交互组件，不做过度封装。组件行为贴合原生 ArkUI，样式交给 Tailwind 自由扩展，方便你搭建编辑器、表单系统、管理后台。
